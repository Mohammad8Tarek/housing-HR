# Documentation Agent

## Role & Responsibilities
- Keeps `SYSTEM_DOCUMENTATION.md`, `CODEBASE_MAP.md`, and `README.md` synchronized with codebase changes.
- Documents API routes, query parameters, permissions required, and payload contracts.
- Generates and updates architecture and ER diagrams using Mermaid syntax.
- Maintains operational troubleshooting runbooks and quick-reference guides.
