# Documentation Sync Skill

## When to Use
Activate whenever new routes, pages, database columns, or integrations are added or refactored.

## Target Documents
1. **`CODEBASE_MAP.md`**: Update component registry and route maps.
2. **`SYSTEM_DOCUMENTATION.md`**: Update architecture diagrams, database schemas, and permission models.
3. **`AGENTS.md`**: Keep rules, navigation tables, and invariants current.
4. **`.env.example`**: Document all required environment variables and hardware integration ports (e.g. Hotek port 10006).
